# 📊 Output

This folder contains the **final analytical outputs** generated by the project.

## What's Here

The CSV files contain results from the SQL analysis, including:

- Monthly unique infusion patients
- Q1 2026 completed treatments
- Highest-volume drug and location combinations
- Monthly drug/location leaders
- Weekly operational metrics
- Data quality summaries

## Goal

Provide **reporting-ready datasets** that can be used for validation, business analysis, visualization, or downstream BI dashboards.

> These files are generated from the analytical pipeline and are not raw source data.
