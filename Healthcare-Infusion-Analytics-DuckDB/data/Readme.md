# 📁 Data

This folder represents the **data layer** used by the project.

## What's Here

The project begins with healthcare infusion operational data containing information related to:

- Patients
- Appointments
- Order series
- Drugs
- Locations
- Medication administration
- PIV attempts
- Authorization information

## Goal

Provide the source data required to build the project's analytical model while maintaining a clear separation between **raw data, transformation logic, and analytical outputs**.

## ⚠️ Data Availability

The original source dataset may not be included in this public repository due to data-sharing and confidentiality considerations.

The project code documents how the source data is ingested and transformed.
